# Security policy

## Supported versions

Only the latest released version receives security fixes.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues.

Use [GitHub private vulnerability reporting](https://github.com/regismarteau/rmediator/security/advisories/new) to send a report. Include the affected version, a description of the issue and, if possible, a minimal reproduction.

You will get an answer as soon as possible, and a fix and an advisory will be published once the issue is confirmed and resolved.
